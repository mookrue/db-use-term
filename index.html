下載、探勘、餵給 AI，
是三種不同的權利。

同一個資料庫，能不能「大量下載」、能不能做「文字探勘（TDM）」、能不能把內容「交給外部生成式 AI／RAG」，往往分屬三套規定。這張表把 19 個常用學術與新聞資料庫的公開條款拆成這三欄，讓你先看結論、再看原文。

⬇大量下載、自動擷取
幾乎全面 禁止。
19 個資料庫都不允許自行以爬蟲、機器人批次抓取。
⛏文字探勘 TDM
最多只到「有條件」。
可行者也須合法近用、非商業、走指定 API 或合約。
✦外部 AI／RAG
沒有一個可直接用。
最好的情況也只是「需另行授權」，多數直接禁止。

Before you start

動手前，先問五個問題

任何一題不確定，就先別開始批次下載，也別把全文交給外部 AI。

1

你拿到的是哪一種近用權？

校園訂閱、個人帳號、開放取用，還是出版社另外提供的 API？來源不同，能做的事也不同。

2

你要的是全文，還是中繼資料？

能下載 DOI、摘要、書目，不代表能批次取得 PDF 或文章全文。

3

用途屬於非商業研究嗎？

多數 TDM 例外只給非商業研究；合作、顧問或產品開發往往需要商業授權。

4

資料會離開核准的環境嗎？

把內容上傳到外部 AI、雲端向量庫或第三方服務，可能構成新的複製、揭露與再利用。

5

合約有沒有明文寫到 AI／RAG？

傳統 TDM 授權不當然涵蓋模型訓練、微調、RAG、評測或提示詞處理。

關於這張表

本頁整理各資料庫平台的公開條款、使用政策與 API 條款，把一般網站使用、TDM、API 與 AI 授權分開判讀，公開條款沒寫清楚的地方標為「未明確」，不把沉默當成同意。

「每小時 500 份 PDF」「一小時 1,000 篇」等數字，是條款用來界定異常／大量使用的門檻，不是允許的下載額度；請勿誤解為配額。

條款會更新。引用於研究計畫、館內指引或採購決策前，請再開啟官方來源確認一次。
