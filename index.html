DECISION GUIDE

開始專案前，先回答五個問題

任何一題不確定，都不宜直接開始批次下載或把全文交給外部 AI。

  1. 01

    你拿到的是什麼權利？

    校園訂閱、個人帳號、開放取用，或出版社另行提供的 API？來源不同，權利也不同。

  2. 02

    你要取得的是全文還是中繼資料？

    可下載 DOI、摘要或書目資料，不代表可批次取得 PDF 或文章全文。

  3. 03

    目的屬非商業研究嗎？

    許多 TDM 例外只限非商業研究；合作、顧問或產品開發可能需要商業授權。

  4. 04

    處理會留在核准環境內嗎？

    把內容上傳到外部 AI、雲端向量庫或第三方服務，可能構成新的複製、揭露與再利用。

  5. 05

    合約是否明文涵蓋 AI／RAG？

    傳統 TDM 授權不當然包含模型訓練、微調、RAG、評測或提示詞處理。

WHAT CHANGED

這次查核最重要的更正

01

限制門檻 ≠ 下載額度

Cambridge 的每小時 500 份 PDF、朝日的每小時 1,000 篇本文，都是異常／大量使用示例，不是允許額度。

02

API ≠ 訂閱全文

IEEE 與 Elsevier 的公開 API 多以中繼資料或 OA 內容為核心，不能推定可取得所有付費全文。

03

TDM ≠ AI 使用權

Sage、Taylor & Francis、Wiley 等明確把研究型 TDM 與 AI／LLM／RAG 分開處理。

04

一般條款 ≠ 機構合約

CNKI 公開頁是個人會員協議；OUP、JSTOR、WARC 等仍須回到校方簽署的訂閱合約。

05

評論文章 ≠ 授權

ACM 對生成式 AI 的觀點不能取代正式 license grant；要找的是明文條款或書面同意。

06

舊頁面 ≠ 現行服務條款

日経テレコン已改採 2026-02-02 修訂條款，並與原表引用的其他新聞服務資料分開判讀。

EVIDENCE RULES

本頁怎麼判讀證據

  • 1優先引用出版社／平台的現行官方條款與政策頁。
  • 2把一般網站使用、TDM、API 與 AI 授權分開，不互相推定。
  • 3公開條款未明確時標示「未明確」，不以沉默當成同意。
  • 4機構合約與個別 OA 授權可能改變結論，應視為最後一層查核。
